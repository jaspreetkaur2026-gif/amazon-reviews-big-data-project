# Amazon Reviews Big Data Analytics

## Course
CS-675 – Big Data Management and Analytics

## Project Overview
This project analyzes Amazon Reviews using Apache Spark and AWS.
The Amazon Reviews dataset will be joined with the Amazon Product Metadata dataset
to analyze customer ratings, popular products, and category trends.

## Technologies
- Python
- Apache Spark (PySpark)
- Amazon S3
- Amazon Athena
- Terraform
- Git & GitHub
- Cursor

## Workflow
1. Test locally using a small sample.
2. Preprocess the data.
3. Join both datasets.
4. Perform Spark SQL analysis.
5. Run the project on AWS.
6. Evaluate the results.
